# pm-portfolio

Live: https://pm-portfolio-bay-delta.vercel.app

Quelle für meine Produkt-Portfolio-Site. Statisches, self-contained HTML, kein Build-Step.

Bilingual (DE/EN, Umschalter), Dark-Mode über `prefers-color-scheme`.

- `index.html`: Übersicht mit How I work, Learning, Selected Work, Stationen
- `case-automations.html`: ein Automations-Feature für Self-Service neu gebaut
- `case-viewar.html`: einen festgefahrenen Enterprise-Rollout wieder in Gang gebracht
- `eval.html`: ein Eval für die Klassifikation von Doku-relevanten Änderungen
